# NASKAH VOICE-OVER BIAN — PROTEKSI KREDIT

> Sumber kebenaran: `src/sales-idea-kredit.js` (`NARASI`). Teks di bawah identik
> dengan yang dipakai aplikasi; `tests/sales-idea-kredit.test.js` memeriksanya.

**Status audio: belum direkam.** Sampai berkas MP3 tersedia, aplikasi memakai
suara browser sebagai cadangan. Tidak ada audio pengganti atau audio sunyi.

## Cara pakai

1. Suara: **Bian — Neutral, Calm and Clear** (ElevenLabs), sama dengan rekaman
   Bian sebelumnya. Referensi pengaturan dari nama berkas rekaman lama:
   `pvc_sp100_s50_sb75_v4`. Voice ID dan API key tidak disimpan di repository.
2. Salin **hanya** isi kotak "TEKS UNTUK ELEVENLABS" — satu segmen per generate.
3. Simpan hasilnya dengan nama file persis seperti tertulis (huruf kecil,
   tanda hubung), lalu kirimkan seluruh 24 berkas.

24 segmen · 2957 karakter · perkiraan durasi Bian ±3,4–3,8 menit.
Folder tujuan di aplikasi: `assets/narasi/kredit/`.
